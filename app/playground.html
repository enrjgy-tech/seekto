Engine playground

Seekto's engine finds dates, deadlines, definitions, practice questions, decisions and action items in plain text, with no AI model and no server. Type or paste below; everything runs in this page.

Use it in your own project

The engine is plain JavaScript modules with no dependencies. Import it straight from the live site or a CDN, or copy engine/src.

import { findEvents, findDefinitions, makeQuiz, findActionItems } from
  "https://cdn.jsdelivr.net/gh/enrjgy-tech/seekto@main/engine/src/index.js";

findEvents("The chapter 5 quiz is on Friday.", { ref: new Date() });
// [{ date: "2026-10-16", type: "test", title: "Chapter 5 quiz", sentence: "…" }]

Missing a phrase or a language? Each one is a test and a rule. See CONTRIBUTING.md.
