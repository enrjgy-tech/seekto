# Code of Conduct

Seekto follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, and keep criticism about the work, not the person. Harassment of any kind isn't tolerated.

To report a problem, contact the maintainers privately through GitHub (open a private security advisory on this repo, or message a maintainer). Reports are kept confidential.
